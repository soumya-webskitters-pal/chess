# Quantum Chess

A glassmorphism chess game built with React, Vite, and three.js via react-three-fiber.

## Features

- AI mode and local two-player mode
- Hint system with bulb icon and move highlighting
- 3-move undo support
- Animated gear settings panel
- Board grid labels and palette themes
- Responsive glass-style interface

## Run

npm install
npm run dev -- --host
